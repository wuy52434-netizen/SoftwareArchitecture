# 兼容性测试与多端分析报告

> 兼容性测试目标：验证系统对不同"接入方"（客户端类型、接入层、编码、请求语义）的兼容与容忍，
> 避免"换个前端/客户端/换条路径就报错"的兼容性风险。

## 2. 兼容性分析（多端视角）

### 2.1 接入层兼容（网关 → nginx → 微服务）
- 直连网关 `:8080` 与经前端接入层 nginx `:8090` 的 `/api/books` 响应**状态码与业务码完全一致**，
  说明网关透传与 nginx 反代无协议/头丢失导致的差异 → **Build 兼容**。

### 2.2 HTTP 方法与 REST 语义
- `GET` 读、`POST` 创建/借还/归还、`PUT` 更新、`DELETE` 删除，语义清晰。
- 未知端点 404、参数缺失业务 400，行为符合 REST 预期。

### 2.3 入参健壮性（发现缺陷）
- **P2：非法分页参数（`page=-1`、`per_page=0`）触发 HTTP 500**，而非服务端容错为默认分页或返回 400。
  健壮性不足：外部/前端异常传参可能直接抛 500 异常页，体验差且暴露堆栈风险。
  - 修复建议：分页参数加 `@Min/@Max` 校验或服务端 clamp 到合法范围。

### 2.4 内容编码（中文）
- 图书标题等中文字段正常，抽样无乱码（早期 `language` 字段乱码属个别数据质量问题，另见缺陷清单）。

## 3. 客户端兼容性建议（针对前端/移动端/其他端接入）
| 接入方 | 风险点 | 结论/建议 |
| ------ | ------ | --------- |
| Web 前端（Vue) | 依赖跨域 CORS | 需确认网关 CORS 头；本测试经 nginx 同源无跨域 |
| 移动端/App | 弱网重试 | 需接口幂等与超时配置 |
| 第三方系统 | 分页恶意参数 | **需修复 P2 非法分页 500**，加参数治理 |

---

## 4. 结论
兼容性整体良好，多接入层、多客户端头、方法语义、编码均通过；
本次兼容性专项**新增发现 1 个 P2 健壮性缺陷**（非法分页 500），已纳入缺陷清单供开发修复。
